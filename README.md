# Hospital Database Management System

A relational database project developed using Oracle SQL to manage core hospital data, including patients, doctors, departments, and appointments.

## Features

- Patient information management
- Patient phone number management
- Doctor and department records
- Doctor-department relationships
- Appointment scheduling
- Primary and foreign key relationships
- Sample data insertion
- SQL queries and aggregate functions
- Database indexing

## Database Tables

- Patient
- PatientPhone
- Doctor
- Department
- DoctorDepartment
- Appointment

## Technologies Used

- Oracle SQL
- Oracle Database
- Oracle FreeSQL
- SQL Developer for VS Code

## SQL Concepts

This project demonstrates:

- CREATE TABLE
- PRIMARY KEY
- FOREIGN KEY
- INSERT INTO
- SELECT queries
- COUNT()
- INITCAP()
- String concatenation
- CREATE INDEX

## Project File

`hospital.sql` contains the complete database schema, sample data, queries, and index creation.
